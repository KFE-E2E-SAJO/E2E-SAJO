### 목적:

- 서비스의 가치를 사용자에게 인지시켜줄 수 있는(Minimum Viable Product) 핵심 기능 버전을 개발합니다.
- 서비스 기획을 분석하고 MVP 기능을 선택하고 구현하는 경험을 제공합니다.
- 실무에서 요구되는 기본적인 서비스 구조 설계 및 개발을 경험합니다.

### 진행 흐름:

1. 사용자 문제 정의
2. 기능 흐름 및 상태 정의
3. MVP 기능 선정
4. 프로젝트 세팅 및 아키텍처 설계
